# Client

The React (Vite) frontend of the Manufacturing Quote Engine: the 3D viewer, the quote UI and the shared geometry engine in `src/engine` (also used by the server).

Live: [manufacturing-quote-engine.vercel.app](https://manufacturing-quote-engine.vercel.app). See the [main README](../README.md) for the full project, setup and deployment.

```bash
npm install
npm run dev     # http://localhost:5173, /api is proxied to the server on :5000
npm test        # Vitest
npm run build   # production build in dist/
```
